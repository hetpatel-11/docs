## Choose Your Path

Auth Agent serves two distinct audiences. Choose the path that matches your role:

<Tabs>
  <Tab title="🤖 For AI Agent Users">
    <Card title="Quick Start for Agents" icon="robot" href="/guides/agent-quickstart">
      Learn how to authenticate your AI agents with websites using browser-use integration
    </Card>
    
    ## What You'll Learn
    
    - How to create agent credentials
    - How to use Auth Agent with browser-use
    - How your agent authenticates automatically
    - Real-world example with code
    
    <Steps>
      <Step title="Create Agent Credentials">
        Visit the [Agent Console](https://auth-agent.com/console/agent) to create your agent credentials
      </Step>
      <Step title="Install SDK">
        Install the Auth Agent SDK for Python
      </Step>
      <Step title="Integrate with browser-use">
        Add Auth Agent tools to your browser-use agent
      </Step>
      <Step title="Test Authentication">
        Your agent will automatically authenticate when needed
      </Step>
    </Steps>
    
    <Card title="View Complete Agent Guide" icon="book" href="/guides/agent-quickstart">
      See the full guide with browser-use example
    </Card>
  </Tab>

  <Tab title="🌐 For Website Developers">
    <Card title="Quick Start for Websites" icon="globe" href="/guides/website-quickstart">
      Learn how to integrate Auth Agent into your website to allow AI agent authentication
    </Card>
    
    ## What You'll Learn
    
    - How to register your OAuth client
    - How to implement the OAuth flow
    - How to handle the three integration scenarios
    - Code examples for each scenario
    
    <Steps>
      <Step title="Register OAuth Client">
        Visit the [Website Console](https://auth-agent.com/console/website) to register your client
      </Step>
      <Step title="Choose Integration Scenario">
        Decide which scenario fits your needs (Full Account, Contextual Profile, or Fresh Profile)
      </Step>
      <Step title="Implement OAuth Flow">
        Add the authorization flow to your website
      </Step>
      <Step title="Handle Callback">
        Process the authorization code and create the appropriate session
      </Step>
    </Steps>
    
    <Card title="View Complete Website Guide" icon="book" href="/guides/website-quickstart">
      See the full guide with all three integration scenarios
    </Card>
  </Tab>
</Tabs>
