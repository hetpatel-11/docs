## Overview

Admin endpoints allow programmatic management of agents and OAuth clients. These endpoints are primarily for internal use or for building custom admin interfaces.

<Warning>
  Admin endpoints currently do not require authentication. In production, these should be protected with proper authentication and authorization.
</Warning>

## Available Endpoints

### Agent Management

| Endpoint | Method | Description |
|----------|--------|-------------|
| [`/api/admin/agents`](/api-reference/admin/agents) | POST | Create a new agent |
| [`/api/admin/agents`](/api-reference/admin/agents) | GET | List all agents |

### OAuth Client Management

| Endpoint | Method | Description |
|----------|--------|-------------|
| [`/api/admin/clients`](/api-reference/admin/clients) | POST | Register a new OAuth client |
| [`/api/admin/clients`](/api-reference/admin/clients) | GET | List all OAuth clients |
| [`/api/admin/clients/update`](/api-reference/admin/clients-update) | POST | Update an OAuth client |
